### 5. Shared Memory 기반 IPC 설계 및 운영 안정성 개선

- `boost::interprocess::managed_shared_memory`를 활용해 공유메모리 세그먼트를 설계하고, C++ 객체를 공유메모리 영역에 직접 적재하는 방식으로 프로세스 간 데이터 공유 지연과 복사 비용을 최소화함.
- `boost::interprocess::offset_ptr`를 적용하여 프로세스별 주소 공간이 달라도 동일 공유메모리 객체를 안정적으로 참조할 수 있도록 포인터 모델을 설계함.
- 공유메모리 상에서 `map` 등 컨테이너를 사용 가능하도록 allocator/객체 수명 관리 방식을 정리하고 다중 프로세스 환경에서 데이터 구조를 일관되게 유지하는 방법을 구현함.
- 운영 중 데이터 소스(파일/DB) 갱신 타이밍 이슈로 인한 부분 로드 실패를 분석하고, 로드 실패 시 기존 공유메모리를 유지하도록 보호 로직을 추가하여 시스템이 “마지막 유효 상태”를 지속하도록 개선함.
- 로드 완료 여부를 단일 플래그에 의존하지 않도록 메타데이터 기반 상태 검증을 도입하고 비정상 상태 감지 시 데이터 소스를 직접 로드하는 Fallback 경로를 구현하여 장애 재발을 방지함.
- `/dev/shm` 기반 공유메모리의 동작을 파일 시스템 관점이 아닌 가상메모리/프로세스 참조 관점에서 해석하여 파일 엔트리 삭제 이후에도 열린 핸들/매핑이 유지되는 조건에서 접근이 가능한 원리를 정리하고 운영 이슈 분석에 활용함.

### 6. 정책 평가 엔진 선별 로직 고도화 및 실행 경로 최적화

- 대량 정책을 순차적으로 평가하던 구조를 개선하기 위해 패턴 매칭 기반 사전 선별 단계를 도입하여 평가 대상 범위를 선제적으로 축소함.
- 복합 조건(and/or 구조)에 따라 선별 대상 제외 조건을 재정의하고 불필요한 필터링을 방지하도록 평가 기준을 정교화함.
- O(N log N) 구성 비용과 O(log N) 탐색 복잡도를 갖는 set 기반 필터링 구조를 제거하고, Thread Local 비트 마킹 모델을 도입하여 인덱스 기반 O(1) 접근 및 Lock 없는 선별 처리 구조로 전환함.
- 선별 결과를 스레드 단위로 분리 관리하여 동시성 환경에서 Lock 경합 없이 안전하게 동작하도록 개선함.
- 선별 작업을 객체 로딩 시점으로 이동시켜 실행 시점 비용을 줄이고 구성 변경이 런타임 평가 경로에 영향을 주지 않도록 안정성을 확보함.
- 해당 기능을 런타임 옵션화하여 운영 환경에 따라 동적으로 활성화/비활성화 가능하도록 확장함.
